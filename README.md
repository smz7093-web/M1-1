# 🏚️ 전국 빈집 13만 4천 호 시계열 추세 및 지역 소멸 리스크 분석

본 프로젝트는 행정안전부·국토교통부·농림축산식품부의 전국 빈집 실태조사 결과(2024년 기준 134,009호)와 통계청(KOSIS) 주택총조사 패널을 바탕으로, **최근 10년간(2015~2024년) 17개 시도별 빈집의 누적 추세, 수도권-비수도권 격차, 변동성 패턴**을 분석한 시계열 데이터 프로젝트입니다.

---

## 📌 주요 분석 결과 요약
* **데이터 규모**: 2015~2024년 17개 광역시·도 패널 시계열 데이터 (총 170개 데이터 포인트)
* **핵심 지표**: 10년간 전국 빈집 약 57.6% 증가 (2015년 약 8.5만 호 → 2024년 13.4만 호)
* **지역 불균형**: 2024년 기준 전체 빈집의 **89.7%(약 12만 호)**가 비수도권에 집중 (전남, 경북, 전북 순)
* **상세 보고서**: 세부 인사이트, 관찰-해석 분석, 한계점 및 시각화는 [REPORT.md](REPORT.md)에서 확인 가능합니다.
